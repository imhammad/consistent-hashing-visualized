💡 Why Not Standard Modulo Hashing hash(key) % N?

With traditional modulo hashing, adding or removing a single server (N \to N+1) causes almost 100% of all keys to remap to different servers, causing a massive cache stampede. With Consistent Hashing, only k/N keys need to move on average when a node is added or removed.
